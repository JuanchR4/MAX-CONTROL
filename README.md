# MAX Control · Dual Robotics
Aplicación Android en Kotlin para MAX MK-42 mediante Bluetooth SPP (HC-05/HC-06). Android 8+; abre `max-control` en Android Studio.

Controles: F adelante, B atrás, L izquierda, R derecha; repetición cada 50 ms y S al soltar. Turbo envía V. La capa Bluetooth está separada para añadir telemetría, batería, sensores, firmware e integración con Jarvis.
